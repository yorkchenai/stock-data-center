```sh
python -m scripts.audit_fund_benchmark_identification work/benchmarks/candidates.json --output work/benchmarks/identification.json
```

`fund_benchmark_sources.py` 保存份额身份、字段、来源和取数时间。`fund_benchmark_formula.py` 保留原文并输出权重、币种、收益口径及候选代码。折算方法不明、动态权重、缺百分号、未知语法、名称或币种冲突均保留明确状态。`fund_benchmark_disclosures.json` 存放经审核的公告、生效起止日及适用份额。当历史起点不确定时，只覆盖有文件支撑的区间。`fund_benchmark_identification.py` 输出 `schema_version`、`official_status`、`regimes`、`engine_status` 和 `history_points_status`。只有适用公式、日期、代码、收益口径及聚合规则都满足现有接口时，才生成可计算基准。官方披露明确不设基准与历史待核实使用不同状态。

本地通过 Python 72 项、Node 32 项和 Chromium 静态构建回归。浏览器覆盖股票五面板与基金桌面、移动端。

对 024808，以真实招募书定义和标明为合成的成分点位验证既有 JavaScript 引擎。已覆盖生效日切换、无点位时留空、历史口径未知时阻止跨区间计算，及 70/10/20 按日加权连乘。未取得获准的真实成分序列，未进行真实超额收益验算。前三阶段的既有三只基准继续使用原登记配置。
