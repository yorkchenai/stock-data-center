# 第八阶段验收 · 基金净值与关联板块图表

## 使用方式

```bash
python -m pip install -r requirements.txt
python -m stock_analysis.web --port 8765
```

访问 [基金 110022 详情](http://127.0.0.1:8765/funds.html?fund=110022) 或在列表搜索六位基金代码。Python 服务只绑定 `127.0.0.1`，用于本地个人分析。净值和收益率可先于关联结果显示，关联首次查询会从中证逐个获取候选指数。相同请求在服务内合并，指数快照缓存 30 分钟，基金关联计算缓存 5 分钟。「检查更新」在当前缓存窗口内复用结果。页面显示净值日期、模型日期、计算时间、所选指数最新日期和过期提示。

静态页面支持既有基金净值 JSON 或单个 `fund_chart_bundle`。仅在数据用途许可涵盖拟导入内容时，用以下命令生成本地文件，并在页面点击「导入 JSON」。将完整市场数据留在本地。

```bash
mkdir -p work
python -m stock_analysis.fund_charts 110022 --output work/fund-110022-charts.json
```

`schema_version: 1` 的图表包包含 `fund`、`analysis` 和 `indices`。本地接口 `GET /api/funds/<code>/sectors` 和 `GET /api/funds/<code>/sectors/<index>` 分别返回关联结果和所选指数历史。导入时检查基金代码、关联日期、指数代码、交易日期和行情字段。成交量文件另需满足[成交量字段合同](off-market-funds-volume.md#成交量字段合同)。静态页面通过文件导入，不会请求第三方行情。在线自动加载需要另行取得使用权限及支持跨域的接口。

## 展示和计算口径

- 历史净值用折线显示。每段复权曲线使用该段锚点单位净值乘以总回报指数与锚点指数之比。复权存疑的日期留空，图表说明断点日期和证据原因。
- 累计收益沿用既有百分比坐标及已确认的官方基准，和历史净值使用相同的区间控件。六张指标卡、风险和持仓区域继续保留。
- 关联识别复用第六阶段模型和候选指数目录，展示最多五条通过筛选的结果。行情视窗变化与 60/120 日关联统计窗口相互独立。Ridge 系数和稳定性采用模型定义，直接持仓支持采用已披露的映射仓位。板块各自有独立可缩放视窗，页面同时显示一个指数。
- 指数可用历史从 2021-01-04 起。MA5/10/20/60 从已校验的完整加载历史计算，展示区间变化仅筛选输出。中证来源是价格指数，单位为点，缺口保留。缺少开高低时使用收盘价折线，行情缺口保留断点。来源确认成交量单位时，价格和成交量以同一图表的 7:3 上下窗格联动。
