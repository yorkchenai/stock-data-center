# 基金关联指数图表 · 股票 OHLCV 引擎

## 本地运行

运行 `python -m stock_analysis.web --port 8765` 后访问[基金分析页面](http://127.0.0.1:8765/funds.html)。关联板块照常由中证历史价格计算。选择关联指数时，回环服务用 `resolve_symbol` 识别指数，直接调用 `fetch_daily`，由股票引擎按原顺序尝试东方财富及腾讯。日K、均线和成交量均来自该次成功响应。图表使用北京时间最近已收盘的开市日作为查询上限。

行情经交易日历校验后，以连续开市日分段调用股票引擎的 `calculate_indicators`。缺口以空值表示，预热从每段首条有效记录开始。`volume_lots` 直接作为图表的 `volume`，单位为手。切换显示区间只裁切结果，MA 和 VOL 保留历史预热。统计模型的指数截止日和图表行情截止日各自按实际数据记录。

本地股票行情路径使用引擎已确认的单位和数值，不需要额外的 `permission`、`scope` 或单位依据 URL。前端保留单位、顺序、行值、数据范围和同一基金及指数的校验。未映射的特殊代码或原股票来源均失败时，继续使用中证原有价格历史，以相应原因提示成交量暂不可用。静态页面及原有图表包导出继续使用既有数据路径，股票引擎的行情通过本地回环请求取得。

## 核验方法

使用 `python -m stock_analysis <标的> --kind index --start 2021-01-04 --end <最近已收盘交易日> --source auto --output-root <本地临时目录>`。浏览器回归通过原基金 API 载入真实基金和板块，检查最新 OHLCV 及右区间均值、两个窗格同步、量能开关、切换清理和移动端触摸。GitHub 审查工作流仅保留截图和单日摘要。
