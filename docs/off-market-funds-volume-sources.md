后续整合见[复用股票 OHLCV 与指标引擎](off-market-funds-stock-chart.md)。以下是整合前的调查结果。

2026-11-24 核验。东方财富网页日线通过了三只核心指数的覆盖和复算检查，技术上比单位未明确的中证网页更适合用于成交量校验。持续自动访问、历史留存和本机图表用途的许可尚未确认。建议优先核实**东财掘金正式指数历史 API**的本地使用条款和账户覆盖，Tushare `index_daily` 为唯一备选。两者目前都没有通过本项目的真实接入验收。

## 本次决定与复核

三只核心指数技术取数 **3/3**，正式启用 **0/3**。24 条候选中本轮替代来源实测 3 条有量且适配文档给出单位，21 条未扩展。本地模式、公开模式与正式真实 VOL5/10 均为 **0/24**。技术观察已可计算 3 条，正式模式当前 24 条均不可用。先前中证网页的 24 条原始字段覆盖保持原报告口径。

最小剩余条件是从东财掘金获得对三个具体代码的**正式日线账户覆盖、成交量单位和本地使用范围**确认。咨询应询明官方 Python API 获取、必要本地缓存、单用户回环网页显示和 VOL 计算四项，并索取适用条款及费用。已有授权的数据文件在核验单位与范围后也可转换为现有图表包，用于许可覆盖的本地模式，减少持续接口依赖。目前没有核实可直接接入的免费方案，也未购买数据。 [图表包字段合同](off-market-funds-volume.md#成交量字段合同)

本次新增的只读探测工具供具备相应用途权限时复核，结果写入本机指定路径。探测输出始终标记 `runtime_eligible: false`。

```bash
python -m scripts.audit_eastmoney_index_volume --end 2026-11-23 --output /tmp/eastmoney-index-volume.json
```

可通过 `--csi-evidence` 指定前轮下载的本地 `observations.json` 复比留存数据。工具按代码和日期比对并记录冲突，无需重新查询中证。

本地通过 Python 105 项、Node 38 项、Pages 静态构建、股票与基金桌面 Chromium 及模拟手机回归。截至本次许可核验，真实量未进入图表，因此没有新的真实成交量窗格截图。缺量降级、合成数据窗格联动与切换清理继续由既有回归覆盖。 [上一轮真实价格图和缺失降级截图](https://github.com/yorkchenai/stock-data-center/actions/runs/45318406464/artifacts/14886957064)
