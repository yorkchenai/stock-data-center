# 场外基金模块

## 使用方式

- **本地个人查询**。运行 `python -m stock_analysis.web --port 8765`，打开 `http://127.0.0.1:8765/funds.html`。基金目录支持名称和六位代码查询。添加后载入确认净值，已有行可手动刷新。源不可访问时页面显示错误，仍可导入文件。
- **GitHub Pages**。在「场外基金」选择「导入净值 JSON」。文件在浏览器内读取，净值不上传，不进入页面部署产物。列表、自选、筛选、排序和列设置保存在当前浏览器，刷新后重新导入或在本地模式按行载入净值。`funds.html?fund=000001` 是场外详情地址，独立于股票代码解析。通过链接直接打开静态详情时，可在该页导入对应文件。
- **场内 ETF**。一级入口保留占位和未接入提示。ETF 联接基金可作为符合范围的场外份额。
- **PR 预览**。在 Actions 的 `pages-review-*` 下载构建产物和桌面、移动截图。也可自行构建 `python -m stock_analysis.pages --output work/funds-preview`，再用 `python -m http.server 8765 --bind 127.0.0.1 --directory work/funds-preview` 打开。PR 沿用既有 Pages 的构建和测试流程。

本地服务默认绑定回环地址，只供个人使用。网络查询使用既有 Python 进程，单次查询限制响应大小和超时，不转发到任意网址。

### 生成个人导入文件

若实际网络及来源许可允许，使用基金接口生成本地文件。也可用 `--snapshot` 读取获准保存的供应商历史脚本文件，`--catalog` 可选提供同源基金目录。本工具只解析指定变量中的 JSON 字面量，不执行脚本。

```bash
python -m stock_analysis.funds 000001 --output work/funds/000001.json
```

另一个入口接受获准使用的披露净值 CSV。列 `date,unit_nav` 必须提供，`accumulated_nav` 和 `return_index` 可选。`return_index` 仅填来源明确标注的分红再投资总回报或同口径复权净值。举例命令不附带真实 CSV。

```bash
python -m stock_analysis.funds 000001 \
  --nav-csv /path/to/disclosed-nav.csv --name 华夏成长混合A \
  --category mixed --manager 华夏基金管理有限公司 --inception 2001-12-18 \
  --source-name 华夏基金管理有限公司 \
  --source-url https://www.chinaamc.com/fund/000001/index.shtml \
  --output work/funds/000001.json
```

`work/` 已被 Git 忽略。请在本地保存获准使用的文件。项目的 Pages 构建不会摄入该目录。

## 文件合同

| 字段 | 规则 |
| --- | --- |
| `schema_version`, `kind` | `1`、`off_market_fund`。股票文件不会进入该路由。 |
| `code`, `name`, `category` | 六位字符串、披露名称和类型枚举。可补充 `manager`、`fund_manager`、`inception`、`size`、`fee`、`reference`。 |
| `source` | `name`、`method`、`retrieved_at` 必须提供，可附 HTTPS `url`。详情显示确认净值日、来源和上海时间的获取时间。 |
| `rows` | 日期递增且唯一，无成立前或未来数据。每行必须有 `date` 和大于零的 `unit_nav`。可填 `accumulated_nav`、`return_index`、`cash_distribution` 和 `split_factor`。 |
| `return_basis` | `event_reinvested`、`adjusted_nav` 或 `unavailable`。跨越未核验分红或折算点的收益和风险不可计算。累计净值只展示。 |
| `valuation_frequency` | 用可靠来源明确标记 `daily` 后，适用基金才显示日频估算的风险指标。QDII、货币、FOF 暂需单独确认。 |
| `benchmark` | 已披露的官方口径，含 `official: true`、`name`、`source` 和可选 `rows: [{date,value}]`。只有实际的对齐累计指数才能画比较曲线及计算超额收益。 |
| `risk_free` | 小数表示的 `annual_rate`、`source`、`effective_from` 和 `effective_to`。利率覆盖整个统计区间。 |
| `holdings`, `related` | 持仓必须包含 `period_end`、`disclosed_at` 与 `source`。关联条目用 `kind`、`name`、`source`，可带 `code`。 |
| `synthetic` | 设为 `true` 时显式标记测试数据，界面测试用。线上默认不载入合成行情。 |

## 日期与计算

- **日期**。列表按每只基金最后一笔确认净值回推。周回推七个自然日，月、年按公历回推并夹到对应月最后一天。取目标日当日或之前最近的净值。周锚点落后超过七天或其余锚点超过十四天时，该周期不可用。目标早于已载入历史时显示 —。详情标明实际生效起止日，历史期、统计期和图表视窗独立。
- **总回报**。显式现金分红或折算事件的相邻系数为 `(本日单位净值 × 每旧份新增后总份数 + 每旧份现金分红) / 上一笔单位净值`。日增长率与该公式偏差超过 0.5 个百分点时，视为待核验。每段的初始指数比例不影响区间收益。未知事件写空，累计净值不代替复权净值。
- **收益、回撤、年化收益**。区间收益为末指数/首指数 − 1。回撤是每个观测点相较于当期此前最高指数的变化，最大回撤取最负值。年化收益用自然日跨度和 365.2425 天。卡玛用年化收益除以最大回撤绝对值。回撤和恢复时间按自然日计。曲线仅使用已观测记录。
- **日频风险**。日收益为相邻有效观测的总回报比率减一，样本标准差乘 √252 年化。至少需要两个日收益样本，相邻记录超过 14 天时不作日频估算。夏普用有出处的年利率按复利折算日利率，以平均日超额收益除以样本标准差，再乘 √252。波动率为零或无风险利率缺失时不计算夏普。索提诺明确使用年化目标 0%，按全部日收益的下行平方均值求根，年化方式相同。下行偏差为零时不可计算。
- **基准**。基金与基准必须在相同生效起点和终点具有可用值，曲线都归零。基准确切日期未匹配时保留空白，不用其他指数或最近数值替代。超额收益为两条收益之差。
- **时效**。已确认净值与实时估值分开。日频已核验基金，最近确认日距今天超过七天会标记日期过旧。该提示不推测各基金实际披露状态，也不使用填充记录。
