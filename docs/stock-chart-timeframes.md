# 股票与指数图表周期

适用范围为股票和指数图表。默认日 K 仍由原日线快照、浏览器日线或已标注的历史样本提供。网页用同一套指标公式重算周 K、月 K 和分时指标。基金、Work、共享快照 Worker 和已部署模型版本不需要随此功能改动。

## 数据口径

- 周 K 从周一分组，月 K 按北京时间自然月分组。每根 K 使用首日开盘、最高价、最低价、末日收盘、成交量与成交额合计。时间轴使用聚合范围内实际最后一个交易日。快照内早于所选起始日的日线可参与指标预热，所选结束日之后的数据不参与。当前交易所周期未收齐时标注「未完成」，历史缺口或日历覆盖未核实也会在明细中区别显示。最后一个日线交易日的完成检查沿用北京时间 15:35 口径。
- 分时主源为东方财富 `push2his.eastmoney.com/api/qt/stock/trends2/get`，请求 `ndays=1`。使用返回的分钟开高低收、成交量、成交额，以及 `f58` 分时均价。指数的均价也是供应商字段，按点位查看，含义与股票成交均价不同。分时均价与 MA 分开展示。
- 分时端不补价格、成交量或缺失时点。指标只在连续到达的分钟片段计算。午间休市不作为分钟数据缺口。ADX14 至少需要 28 条，RSI14 至少需要 15 条，MACD 的显示门槛为 34 条。指标引擎内部的顺序键不会进入画图或伪装成行情日期。
- 图表用北京时间显示源分钟标签、接口时间（可用时）和网页收取时间。供应商给出的分钟标签可能采用区间结束时刻，形成中的分时点会更新。交易时段每 30 秒尝试一次，休市、午间、收盘后和页面隐藏时停用自动请求。盘前与非交易日可明确标注最近交易日行情。手动刷新保留，失败时保留上次成功结果及其时间。超过 90 秒的观测差异会提示延迟，其他交易时段显示「实时等级未核实」。刷新间隔不代表上游的更新频率或真实时效。
- 旧版纯离线样本如果没有交易日历，仅能使用历史聚合。分时需要有效的交易日历和浏览器网络。

## 真实接口与单位核对

2026-11-27 北京时间 14:52 至 15:00 实测科创50（000688）、贵州茅台（600519）、思创智联（300078）、中芯国际（688981）、深证成指（399001）。五个标的均获得同一交易日的真实分时响应，收盘后分别取得 **241 条**记录，涵盖 09:30 开盘参考点及两段连续交易的分钟标签至 15:00。

| 指标 | 实测结果 |
| --- | --- |
| 盘中请求时间 | 14:55–14:56 成功请求约 1.78–5.57 秒 |
| 接口时间与收到响应的差 | 同一批次成功样本约 1.70–5.16 秒。该观测差无法证明交易所到终端的真实延迟 |
| 完整性样本 | 五只标的收盘分钟序列均无缺口。开盘价与最终收盘价和当日同源日线一致 |
| 成交量 | `f56` 按手展示与聚合。对照同源日线，科创50合计一致，其余样本差 1–2 手。日线与分钟成交额分别对照，绝对差为 0–488.32 元 |
| CORS | 真实 HTTP 响应对 GitHub Pages、回环开发及隔离 Site 三个请求 Origin 分别返回相应允许来源。本地 Chromium 直连行情时遇到环境代理证书拒绝，未关闭证书验证 |
| 可用性 | 盘中三轮 15 次请求出现 5 次 HTTP 503，收盘批次 2 次失败后单独重试成功。未核实公开限频或实时服务承诺 |

腾讯的分时与分钟 K 接口一并探测过。分时返回收盘价和累计量额，分钟 K 在本次样本中的临近时点和量额字段与前者存在差异。未混合两种口径，也未使用腾讯补填东方财富分时缺口。东方财富服务仍需要关注波动和使用条款。

## 验证与复现

- `npm test` 覆盖真实仓库日线聚合、指标重算、缺段与预热、沪深交易时钟、日期和字段验证。
- `npm run test:browser` 使用已保存的真实历史数据，覆盖网页日 K、周 K、月 K 与既有浏览器操作。另用上述三只代表标的的实采响应在 Chromium 1440px、390px 视口验收四周期，核对五个面板、选择状态与日 K 恢复。通过可控浏览器时钟检查 30 秒轮询、手动刷新、午间与收盘暂停，以及 503 后保留旧时间。回放实采响应的测试与真实取数探测独立。
- 用 Python/Pandas 从同一批日线重新分组，核对开高低收、成交量与成交额，再用现有独立 Python 指标实现复算周、月和分钟数据。三个标的共核对每只 354 周、83 月和 241 个分钟点。核对的指标最大绝对误差约 `9.1e-13`。
- 使用 `.github/pages-worker-build.json` 构建候选 Pages 与现有 Worker 兼容版本。只在独立开发分支验证，无正式发布。
